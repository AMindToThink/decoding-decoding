## Per-citation findings

### `basu2021mirostat` — Mirostat (arXiv:2007.14966) — Supported
- Feedback control loop on per-token surprise: **Supported** (§4 / Algorithm 1:
  error `e = 𝔖(X) − τ`, update `μ ← μ − η·e`; abstract "feedback-based adaptive
  top-k").
- Target is a single fixed/aggregate value that cannot adapt to local context:
  **Supported** (Algorithm 1 target cross-entropy τ; abstract "predetermined
  target value of perplexity").
- **LOW note:** "aggregate per-token surprise" is fair but slightly loose — the
  controller steers each token's surprise toward a single *global* target via a
  running update, not a post-hoc batch average. "a control loop on per-token
  surprise toward a fixed target" would be marginally more precise. The current
  wording matches the project proposal and is defensible; left as-is.

### `guo2017calibration` — On Calibration of Modern Neural Networks (arXiv:1706.04599) — Supported
- Post-hoc temperature scaling, single scalar T dividing logits: **Supported**
  (§4.2 "Temperature Scaling", Eq. 9).
- T fit by minimizing NLL on validation ("Guo MLE"): **Supported** ("T is
  optimized with respect to NLL on the validation set").
- **LOW note:** calibration is *measured* by ECE in the paper, but T is *fit* by

  change needed.
